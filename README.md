# aramos-assets

Public web assets for the ARAMOS store on Zid (aramos.zid.store), served through jsDelivr.

## Fonts

- `fonts/year-of-the-camel-400.woff`, `fonts/year-of-the-camel-700.woff`: Arabic subsets of
  *The Year of The Camel* (خط عام الإبل), released free for use by the Saudi Ministry of Culture.
  Only the Arabic letters, digits and punctuation the store needs are included.
- `fonts/aramos-fonts.css`: loads the two Arabic weights plus Sora (SIL Open Font License) from Google Fonts.

CDN: `https://cdn.jsdelivr.net/gh/rakan200291-cloud/aramos-assets@main/fonts/aramos-fonts.css`
